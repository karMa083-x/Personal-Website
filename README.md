# Stan Xu ePortfolio

Open `index.html` to preview the site locally.

## Publish on GitHub Pages

1. Create a public repository named `ece-eportfolio`.
2. Upload the contents of this folder to the root of the repository on `main`, including the `visuals` folder. Keep `index.html` at the repository root. If your file picker hides `.nojekyll`, create an empty file with that name in the repository.
3. Go to **Settings → Pages**. Select **Deploy from a branch**, then choose **main** and **/ (root)**. Save.
4. When GitHub shows **Visit site**, open it in a signed-out browser window and check the portrait and résumé download. Submit that published URL in Canvas.
